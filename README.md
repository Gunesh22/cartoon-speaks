# Cartoon Speaks — 2D Lip-Sync Animation Studio (MVP)

A client-side-first, local-only 2D animation web application that allows users to create talking cartoon characters by combining character illustrations, mouth shape sprite sheets, dialogue scripts, and audio recordings.

---

## Key Highlights & Architectural Guarantees

1. **100% Local Processing & Static Deployment**
   - Runs completely in the user's browser.
   - Deployable as static files (`dist/`) to GitHub Pages, Cloudflare Pages, Vercel, or any static web host.
   - No remote server, cloud storage, paid APIs, user accounts, or Firebase.

2. **IndexedDB Local Storage via Dexie.js**
   - User characters, mouth sprite sheets, extracted transparent crops, projects, and audio files persist across browser reloads.
   - Large binary assets are stored directly as native `Blob` objects rather than bloated base64 strings.
   - Includes full project backup export (`.json`) and restoration.

3. **Strict Separation of Coordinate Systems**
   - **Source Sprite-Sheet Crop Coordinates**: Boundaries relative to the source image.
   - **Extracted Mouth Dimensions**: Standalone transparent image assets.
   - **Normalized Character-Space Placement**: Normalized percentages (`normalizedX`, `normalizedY` in `[0.0, 1.0]`, relative scale, rotation, and anchor).
   - **Export Canvas Dimensions**: 9:16 portrait, 16:9 landscape, 1:1 square, 4:5 portrait, and fit modes (`contain` / `cover`).
   - Changing the export canvas or switching from portrait to landscape **never** recalculates, shifts, or overwrites the character's saved mouth placement!

4. **Zero-Adjustment Mouth Sprite Sheet Importer & Review Grid**
   - Strict standard 3×3 template format (Shapes: **A, B, C, D, E, F, G, H, X**).
   - Shows **all detected mouth crops simultaneously in an interactive review grid** with warnings for clipping, excessive padding, or blank cells.
   - Supports importing individual transparent PNGs with automated label assignment.
   - Seamless collection replacement: replace an entire mouth sheet while retaining stable asset IDs and character mouth placement.

5. **Lip-Sync Engine Architecture (Rhubarb & Browser Phonetic Aligner)**
   - Rhubarb Lip Sync reference: [https://github.com/DanielSWolf/rhubarb-lip-sync](https://github.com/DanielSWolf/rhubarb-lip-sync)
   - **Local Rhubarb Companion Runner**: Optional zero-dependency local companion (`rhubarb-companion.mjs`) to execute the native `rhubarb` CLI locally without cloud processing.
   - **Direct Rhubarb File Import**: Drag & drop or upload `.json` or `.tsv` files generated by Rhubarb.
   - **Built-in Browser Engine**: Offline audio energy envelope analyzer and phonetic script cadence generator that runs 100% in-browser with zero external dependencies.
   - Full manual timeline editing: add, move, delete, adjust cues, and change phoneme shapes.

6. **Client-Side Video Export**
   - WebCodecs `VideoEncoder` + in-browser muxing (`mp4-muxer` and `webm-muxer`).
   - Runtime codec detection with graceful `MediaRecorder` fallback.
   - **Standard MP4**: Universally playable H.264 video with background.
   - **Transparent WebM (VP9/VP8)**: Real alpha-channel transparency for video editors (Premiere, DaVinci, Final Cut, OBS).
   - Incremental frame rendering to protect memory.

## Getting Started

### 1. Installation

```bash
cd "d:/cartoon speaks"
npm install
```

### 2. Development Server

```bash
npm run dev
```

Open your browser at `http://localhost:3000`.

### 3. Running Unit Tests

```bash
npm run test
```

### 4. Production Static Build

```bash
npm run build
```

The output in `dist/` is ready for zero-backend static deployment.

## Using Rhubarb Lip Sync

### Option A: Built-in Browser Engine (Zero Setup)
No installation required. Upload audio, enter dialogue, and click **"Generate Lip-Sync Timeline"**. The app analyzes the speech energy and phonetic timing directly in your browser.

### Option B: Local Rhubarb CLI Companion (High Precision)
1. Download Rhubarb Lip Sync from GitHub:
   [https://github.com/DanielSWolf/rhubarb-lip-sync/releases](https://github.com/DanielSWolf/rhubarb-lip-sync/releases)
2. Ensure `rhubarb` (or `rhubarb.exe`) is in your system PATH.
3. Start the local companion:
   ```bash
   node rhubarb-companion.mjs
   ```
4. The web app detects `http://127.0.0.1:8765/health` and automatically uses your native Rhubarb CLI!

### Option C: Rhubarb File Import
Run Rhubarb manually on your terminal:
```bash
rhubarb -f json -r phonetic speech.wav -o cues.json
```
In the web app, click **"Import Rhubarb File"** and select `cues.json`.

## AI Prompt for Generating Compatible Mouth Sheets

Use the button in the Mouth Importer tab or copy this prompt for image generators:

```text
Create a high-resolution 2D cartoon lip-sync sprite sheet for the supplied character's existing art style.
Requirements:
- Generate isolated mouth shapes only. Do not include a face, head, body, background scene, or decorative elements.
- Arrange the mouth shapes in a clean, evenly spaced 3x3 grid.
- Include the standard Rhubarb mouth labels: A, B, C, D, E, F, G, H, and X.
- Keep every mouth front-facing, with consistent line thickness, shading, proportions, and visual style.
- Include a neutral closed mouth (A), slightly open mouth (B), open mouth (C), wide open mouth (D), rounded mouth (E), puckered mouth (F), teeth on lip (G), tongue behind teeth (H), and resting mouth (X).
- Use genuine alpha transparency (PNG).
- Keep generous spacing between mouths so automatic cropping is zero-effort.
- Do not put labels, shadows, or decorative graphics inside the mouth image itself.
```

## Video Export & Codec Compatibility

- **MP4 (H.264)**: Export with a solid or image background. Universal playback on Windows, Mac, iOS, Android, and social media platforms.
- **WebM with Alpha (VP9/VP8)**: Available when browser WebCodecs supports alpha keeping. Delivers genuine transparency for compositing into video editing software.
- Standard MP4 does not support alpha transparency (per format standard); select WebM when transparent background export is required.
